Linked Lists

Learn how Linked Lists store and connect data using nodes, how they work, and when to use them in real-world applications.

Previous Next
Introduction

What Is a Linked List?

A Linked List is a linear data structure made up of individual elements called nodes. Each node stores data and a reference to another node in the list.

The Main Idea

Think of a Linked List like a chain. Each link represents a node, and each node points to the next one. Unlike an array, the nodes do not need to be stored next to each other in memory.

Node 1
10 Next
Node 2
20 Next
Node 3
30 Next
NULL
Remember

A Linked List consists of nodes. Each node stores data and a link to the next node. The last node points to null, which means there is no next node.

Why It Matters

Why Do We Use Linked Lists?

Linked Lists are useful when we need a collection of elements that can grow or shrink dynamically.

Dynamic Size

A Linked List can grow or shrink as elements are added or removed.

Flexible Insertion

Nodes can be inserted by updating links without shifting all the following elements.

Flexible Removal

Removing a node can be done by updating the links between neighboring nodes.

Important

Linked Lists do not provide direct index access like arrays. To find an element, we usually start at the head and move through the nodes one by one.

Fundamentals

Structure of a Node

A node is the basic building block of a Linked List. In a simple singly linked list, each node contains two main parts.

01

Data

Stores the value or information represented by the node.

02

Next Pointer

Stores a reference to the next node in the list. The last node points to null.

JavaScript Example 
// Create a Node class
class Node {
    constructor(data) {
        this.data = data;
        this.next = null;
    }
}

// Create a node
const firstNode = new Node(10);

console.log(firstNode.data); // 10
console.log(firstNode.next); // null
What Happens Here?

We create a Node class with a data property and a next property. When we create a node with the value 10, its next property starts as null.

Key Concepts

Head and Tail

Two important terms help us understand where a Linked List starts and ends.

Start

Head

The Head is a reference to the first node in the Linked List.

End

Tail

The Tail refers to the last node. In a singly linked list, its next property is null.

Head
10 Next
20 Next
30 NULL
Tail
Types

Types of Linked Lists

Linked Lists come in different forms. The main difference is how their nodes are connected.

01

Singly Linked List

Each node points to the next node. Traversal normally moves in one direction.

10 20 30 NULL
02

Doubly Linked List

Each node points to both the next node and the previous node, allowing traversal in both directions.

NULL 10 20 30 NULL
03

Circular Linked List

The last node points back to the first node, forming a circle instead of ending with null.

10 20 30
Quick Comparison

Singly Linked Lists move forward, Doubly Linked Lists can move forward and backward, and Circular Linked Lists connect the last node back to the first.

Comparison

Linked Lists vs. Arrays

Both structures store collections of data, but they organize and access that data differently.

Feature Array Linked List
Memory Layout Elements are stored contiguously in typical array implementations. Nodes can be stored in different memory locations.
Access by Index Fast O(1) Sequential O(n)
Insertion at the Beginning May require shifting elements. O(1) when the Head is available.
Extra Memory Usually no pointer per element. Nodes need references to other nodes.
Size Depends on the array implementation. Can grow or shrink dynamically.
Keep in Mind

Inserting or deleting a node is not always O(1). Finding the correct position may first require traversing the list, which takes O(n) time.

Operations

Basic Linked List Operations

These are the common operations used to work with a Linked List.

Insertion

Add a new node to the list.

Deletion

Remove a node from the list.

Searching

Find a node that contains a specific value.

Traversal

Visit nodes one by one from the Head.

Traversing a Linked List 
// Assume head points to the first node
let current = head;

while (current !== null) {
    console.log(current.data);
    current = current.next;
}

The loop starts at the Head, prints each node's data, and moves to the next node until it reaches null.

Performance

Time Complexity

The performance of a Linked List operation depends on where the operation happens and whether we already have a reference to the required node.

Operation Typical Time Complexity
Access by Position O(n)
Search by Value O(n)
Insert at the Head O(1)
Delete the Head O(1)
Insert After a Known Node O(1)
Complexity Depends on the Situation

These values describe common singly linked list operations. If you must search for a node first, that search can add O(n) time. Doubly linked lists and lists that maintain a Tail reference can have different costs for certain operations.

Summary

Advantages and Disadvantages

Linked Lists are useful in some situations, but they are not always the best choice.

Advantages

  • Can grow and shrink dynamically.
  • Efficient insertion at the Head.
  • No need for contiguous memory locations.
  • Useful for implementing other data structures.

Disadvantages

  • No direct access by index.
  • Searching usually takes linear time.
  • Extra memory is needed for references.
  • Pointer management makes implementation more complex.
Review

Key Takeaways

Review the most important ideas from this lesson.

A Linked List is made up of connected nodes.

Each node stores data and one or more references.

The Head identifies the first node in the list.

In a singly linked list, the last node points to null.

Linked Lists support flexible insertion and deletion, but accessing a node by position usually takes O(n).
