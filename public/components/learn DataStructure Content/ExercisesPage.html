Introduction Exercise 1

What is the primary purpose of a data structure?

Correct Answer

B. To organize and manage data efficiently.

Explanation: Data structures organize data so that operations such as searching, insertion, deletion, and retrieval can be performed effectively.

Introduction Exercise 2

Which of the following is a linear data structure?

Correct Answer

C. Queue.

Explanation: A queue stores elements in a sequence and follows the FIFO principle: First In, First Out.

Fundamentals Exercise 1

What does Big O notation describe?

Correct Answer

A. How an algorithm's resource usage grows with input size.

Explanation: Big O describes an upper-bound growth rate, commonly used to discuss time and space complexity.

Fundamentals Exercise 2

Which complexity grows linearly with the input size n?

Correct Answer

D. O(n).

Explanation: Linear complexity means the amount of work grows proportionally to the input size.

Stack Exercise 1

Which principle does a stack follow?

Correct Answer

B. LIFO — Last In, First Out.

Explanation: The last element pushed onto a stack is the first element removed using pop().

Queue Exercise 2

Which operation typically adds an element to a queue?

Correct Answer

A. Enqueue.

Explanation: Enqueue inserts an element at the rear of a queue, while dequeue removes an element from the front.

Linked List Exercise 3

What does a node in a singly linked list usually contain?

Correct Answer

C. Data and a reference to the next node.

Explanation: In a singly linked list, each node stores its data and a link to the next node. The last node typically points to null.

Hash Tables Exercise 1

What is the purpose of a hash function?

Correct Answer

D. To map a key to a hash value or table index.

Explanation: A hash function transforms a key into a value used to determine where the associated data should be stored or searched for.

Collision Handling Exercise 2

What is a hash collision?

Correct Answer

B. When two different keys map to the same hash location.

Explanation: Collisions can be handled using techniques such as separate chaining or open addressing.

Trees Exercise 1

What is the topmost node of a tree called?

Correct Answer

A. Root.

Explanation: The root is the starting node of a tree. A leaf is a node with no children.

Binary Search Trees Exercise 2

In a typical Binary Search Tree, where are smaller values stored?

Correct Answer

C. In the left subtree.

Explanation: In the standard BST ordering rule, values smaller than a node are placed in its left subtree, and larger values in its right subtree. Duplicate values depend on the chosen implementation.

Graphs Exercise 3

What are the fundamental components of a graph?

Correct Answer

D. Vertices and edges.

Explanation: Vertices represent entities, while edges represent connections between those entities.

Code Tracing Exercise 1

What is the output of this stack operation sequence? 

const stack = [];

stack.push(10);
stack.push(20);
stack.pop();

console.log(stack[stack.length - 1]);
Correct Answer

B. 10.

Explanation: The stack first contains 10 and 20. The pop() operation removes 20, leaving 10 at the top.

Complete the Code Exercise 2

Complete the statement with the queue operation that adds an element to the rear. 

const queue = [];

queue.________(42);
Correct Answer
queue.enqueue(42);

Explanation: Enqueue is the conventional name for adding an element to a queue. The exact method name depends on the queue implementation being used.
