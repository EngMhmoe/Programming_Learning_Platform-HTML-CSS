Stacks

Learn how Stacks organize data using the Last In, First Out principle, how stack operations work, and when to use them in real-world applications.

Previous Next
Introduction

What Is a Stack?

A Stack is a linear data structure that follows the Last In, First Out (LIFO) principle. The last element added to the Stack is the first element removed.

The Main Idea

Think of a Stack like a pile of plates. You place a new plate on top, and when you need one, you remove the top plate first. You do not normally remove a plate from the middle of the pile.

Top
30 Last In
Element 2
20 Earlier
Bottom
10 First In
Remember

LIFO means Last In, First Out. If we push 10, then 20, then 30, the first value removed by pop() will be 30.

Why It Matters

Why Do We Use Stacks?

Stacks are useful whenever the most recently added item needs to be processed first.

Undo Operations

Applications can store previous actions and undo the most recent action first.

Function Calls

Programs use a call stack to manage function calls and return to the previous function.

Backtracking

Stacks help track previous states when solving problems or navigating through choices.

Important

A Stack restricts the normal insertion and removal operations to its top. This makes the LIFO order predictable and useful for many algorithms.

Fundamentals

Structure of a Stack

A Stack contains a collection of elements and keeps track of the top element, which is the point where elements are normally added and removed.

01

Elements

The values stored in the Stack. Their order determines which value will be removed next.

02

Top

Identifies the most recently added element. Push and pop operations work at this end.

JavaScript Example 
// Create a Stack using an array
const stack = [];

// Add elements to the Stack
stack.push(10);
stack.push(20);
stack.push(30);

console.log(stack); // [10, 20, 30]

// The top element is the last array element
console.log(stack[stack.length - 1]); // 30
What Happens Here?

We use a JavaScript array to represent a Stack. Each call to push() adds an element to the top, which is the end of the array in this implementation.

Key Concepts

The LIFO Principle

LIFO describes the order in which elements leave a Stack: the last element added is the first one removed.

Add

Push

Adds a new element to the top of the Stack.

Remove

Pop

Removes and returns the top element of the Stack.

Pop First
30 Top
20 Middle
10 Bottom
Example

If we push 10, 20, and 30 in that order, calling pop() returns 30 first, followed by 20, then 10.

Operations

Basic Stack Operations

These are the main operations used to add, remove, inspect, and check elements in a Stack.

01

Push

Adds a new element to the top of the Stack.

Example 
const stack = [10, 20];

stack.push(30);

console.log(stack); // [10, 20, 30]
02

Pop

Removes and returns the top element. If the Stack is empty, JavaScript's array pop() returns undefined.

Example 
const stack = [10, 20, 30];

const removed = stack.pop();

console.log(removed); // 30
console.log(stack);   // [10, 20]
03

Peek

Reads the top element without removing it. With an array-based Stack, we can inspect the last element directly.

Example 
const stack = [10, 20, 30];

const top = stack[stack.length - 1];

console.log(top);   // 30
console.log(stack); // [10, 20, 30]
04

isEmpty

Checks whether the Stack contains any elements. In an array-based implementation, an empty array means the Stack is empty.

Example 
const stack = [];

const isEmpty = stack.length === 0;

console.log(isEmpty); // true
Quick Summary

push() adds an element, pop() removes the top element, peek reads the top element, and isEmpty checks whether the Stack contains any elements.

Implementation

Implementing a Stack in JavaScript

We can create a simple Stack class using an array and methods that follow the LIFO principle.

Stack Class 
class Stack {
    constructor() {
        this.items = [];
    }

    push(element) {
        this.items.push(element);
    }

    pop() {
        if (this.isEmpty()) {
            return undefined;
        }

        return this.items.pop();
    }

    peek() {
        if (this.isEmpty()) {
            return undefined;
        }

        return this.items[this.items.length - 1];
    }

    isEmpty() {
        return this.items.length === 0;
    }

    size() {
        return this.items.length;
    }
}

// Create a Stack
const stack = new Stack();

stack.push(10);
stack.push(20);
stack.push(30);

console.log(stack.peek()); // 30
console.log(stack.pop());  // 30
console.log(stack.size()); // 2
console.log(stack.isEmpty()); // false
How It Works

The items array stores the values. The push() and pop() methods add and remove values at the end of the array. The other methods inspect the Stack without changing its contents.

Comparison

Stack vs. Queue

Stacks and Queues are both linear data structures. Their main difference is the order in which elements are removed.

Feature Stack Queue
Principle LIFO — Last In, First Out FIFO — First In, First Out
Insertion At the top At the rear
Removal From the top From the front
Common Operations push(), pop() enqueue(), dequeue()
Common Uses Undo, function calls, backtracking Task scheduling, waiting lines, buffering
Easy Way to Remember

A Stack behaves like a pile of plates: the last plate placed on top is removed first. A Queue behaves like a waiting line: the first person to arrive is served first.

Performance

Time Complexity of Stack Operations

With a typical array-based Stack, adding or removing an element at the end takes constant time on average.

Operation Time Complexity
Push O(1) amortized
Pop O(1)
Peek O(1)
isEmpty O(1)
Size O(1)
Search for a Value O(n)
Important

Array resizing can make an individual push() operation take O(n) time. However, for a dynamic array, push() is typically O(1) amortized over many operations.

Summary

Advantages and Disadvantages

Stacks are simple and efficient for LIFO operations, but their restricted access makes them unsuitable for some tasks.

Advantages

  • Simple to understand and implement.
  • Efficient push and pop operations.
  • Useful for function calls and recursion.
  • Helps implement undo and backtracking features.

Disadvantages

  • Only the top element is directly accessible through normal Stack operations.
  • Searching for a specific element may take linear time.
  • Removing elements in the middle is not a standard Stack operation.
  • An implementation may need to handle empty Stack cases.
Review

Key Takeaways

Review the most important ideas from this lesson.

A Stack is a linear data structure that follows LIFO.

The top element is the first one removed.

push() adds an element, while pop() removes the top element.

peek() reads the top element without removing it.

Stacks are useful for undo operations, function calls, recursion, and backtracking.
