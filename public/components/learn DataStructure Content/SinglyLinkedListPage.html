Singly Linked List

Learn how a Singly Linked List works, how nodes are connected, and how to insert, delete, search, and traverse elements using simple examples.

Previous Next
Introduction

What Is a Singly Linked List?

Understand the basic idea before learning its operations.

A Singly Linked List is a linear data structure made of small units called nodes. Each node stores data and a reference to the next node in the list.

Unlike an array, the nodes of a linked list do not need to be stored next to each other in memory. They are connected through references.

The Main Idea

Every node knows where the next node is. The first node is called the Head, and the final node points to null, which means there is no next node.

Singly Linked List Structure
Head
Data 10
Next
Data 20
Next
Data 30
Next
null

Each node stores data and a reference to the next node.

Remember

A Singly Linked List can only move forward from one node to the next node. It cannot directly move backward.

Fundamentals

Structure of a Node

Every node has two main parts.

01

Data

Stores the actual value of the node, such as a number, a name, or any other information.

Example data = 10
02

Next Reference

Stores a reference to the next node. If the node is the last one, its next reference is null.

Example next = nextNode
Node Example in JavaScript
JavaScript 
class Node {
    constructor(data) {
        this.data = data;
        this.next = null;
    }
}

const firstNode = new Node(10);

console.log(firstNode.data); // 10
console.log(firstNode.next); // null

Code Explanation

  • class Node defines the structure of a node.
  • this.data = data stores the supplied value.
  • this.next = null means the node is not connected to another node yet.
  • new Node(10) creates a node that stores the value 10.
Important Concepts

Head and Tail

Learn how we access the beginning and end of a list.

Head

The Head references the first node in the linked list. We use it to access the beginning of the list.

head

Tail

The Tail is the last node in the list when a Tail reference is maintained. Its next value is null.

tail.next = null
Important Difference

A linked list always needs a way to identify its Head. A Tail reference is optional and depends on the implementation.

Implementation

Creating a Singly Linked List

Connect multiple nodes to create a complete list.

Creating and Connecting Nodes
JavaScript 
class Node {
    constructor(data) {
        this.data = data;
        this.next = null;
    }
}

const first = new Node(10);
const second = new Node(20);
const third = new Node(30);

first.next = second;
second.next = third;

let head = first;

How Does It Work?

  1. Create three separate nodes.
  2. Connect the first node to the second node.
  3. Connect the second node to the third node.
  4. Set head to the first node.
  5. The third node still points to null.
The Result
head
10 20 30 null
Basic Operations

Traversing a Singly Linked List

Traversal means visiting nodes one by one.

To traverse a linked list, start from the Head and follow the next reference until you reach null.

Traverse the List
JavaScript 
function traverse(head) {
    let current = head;

    while (current !== null) {
        console.log(current.data);
        current = current.next;
    }
}

Step by Step

  1. current = head starts at the first node.
  2. while (current !== null) continues as long as a node exists.
  3. console.log(current.data) prints the current node's data.
  4. current = current.next moves to the next node.
  5. When current becomes null, the loop stops.
Output 
10
20
30
Common Mistake

Always move to the next node inside the loop. Otherwise, current never changes and the loop may run forever.

Basic Operations

Searching for a Value

Find whether a value exists in the list.

A Singly Linked List does not provide direct index-based access like an array. To search for a value, we begin at the Head and check each node until we find the value or reach the end.

Search Example
JavaScript 
function search(head, target) {
    let current = head;

    while (current !== null) {
        if (current.data === target) {
            return true;
        }

        current = current.next;
    }

    return false;
}

Understand the Logic

  • target is the value we want to find.
  • If the current node contains the target, the function returns true.
  • If no node matches, the function returns false.
20 Found
50 Not Found
Basic Operations

Insertion in a Singly Linked List

Insertion means adding a new node to the list.

01

Insert at the Beginning

Add a new node before the current Head.

Insert at Beginning 
function insertAtBeginning(head, value) {
    const newNode = new Node(value);

    newNode.next = head;

    return newNode;
}

What Happens?

  1. Create the new node.
  2. Point its next to the old Head.
  3. Return the new node as the new Head.
Before
10 20 null
After adding 5
5 10 20 null
02

Insert at the End

Connect a new node after the last node.

Insert at End 
function insertAtEnd(head, value) {
    const newNode = new Node(value);

    if (head === null) {
        return newNode;
    }

    let current = head;

    while (current.next !== null) {
        current = current.next;
    }

    current.next = newNode;

    return head;
}

What Happens?

  1. Create the new node.
  2. If the list is empty, the new node becomes the Head.
  3. Otherwise, move until the last node.
  4. Set the last node's next to the new node.
  5. Return the original Head.
03

Insert After a Specific Node

Insert a new node after a node you already have.

Insert After a Node 
function insertAfter(node, value) {
    if (node === null) {
        return;
    }

    const newNode = new Node(value);

    newNode.next = node.next;
    node.next = newNode;
}
Why This Order Matters

First connect the new node to the node that comes after the current node. Then connect the current node to the new node. This preserves the rest of the list.

Basic Operations

Deletion in a Singly Linked List

Deletion removes a node by changing references.

01

Delete the First Node

Move the Head to the second node.

Delete at Beginning 
function deleteAtBeginning(head) {
    if (head === null) {
        return null;
    }

    return head.next;
}

If the list is empty, the function returns null. Otherwise, the second node becomes the new Head.

02

Delete a Node by Value

Find the target and skip it in the chain.

Delete by Value 
function deleteByValue(head, target) {
    if (head === null) {
        return null;
    }

    if (head.data === target) {
        return head.next;
    }

    let current = head;

    while (
        current.next !== null &&
        current.next.data !== target
    ) {
        current = current.next;
    }

    if (current.next !== null) {
        current.next = current.next.next;
    }

    return head;
}

How Does Deletion Work?

  1. Check whether the list is empty.
  2. Check whether the target is in the Head node.
  3. Search for the node immediately before the target.
  4. Skip the target by setting current.next to current.next.next.
  5. Return the Head of the updated list.
Important

In a Singly Linked List, you generally need to reach the node before the one you want to delete, because each node only points forward.

Performance

Singly Linked List Time Complexity

Understand how the running time changes with the number of nodes.

Operation Time Complexity Reason
Access by Position O(n) Move through nodes to reach the position.
Search by Value O(n) The value may be at the end or absent.
Insert at Beginning O(1) Only a few reference updates are needed.
Delete at Beginning O(1) Move the Head to the next node.
Insert at End O(n) Without a Tail reference, find the last node.
Delete by Value O(n) Find the target and its previous node.
What About a Tail Reference?

Maintaining a Tail reference can make insertion at the end O(1). However, deleting the last node in a singly linked list still generally requires finding the node before it, which takes O(n).

Comparison

Advantages and Disadvantages

Every data structure has strengths and limitations.

Advantages

  • Dynamic size that can grow or shrink.
  • Fast insertion at the beginning.
  • Fast deletion at the beginning.
  • No need for contiguous memory allocation.
  • Useful when frequent insertions and deletions are needed.

Disadvantages

  • No direct access by index.
  • Searching usually takes linear time.
  • Cannot move backward through the list.
  • Each node needs extra memory for its next reference.
  • Deleting a node often requires finding its predecessor.
Summary

Key Takeaways

Review the most important points from this lesson.

  • A Singly Linked List consists of nodes connected through their next references.

  • Each node contains data and a reference to the next node.

  • The Head identifies the first node, while the last node points to null.

  • Traversal and searching usually take O(n) time.

  • Insertion and deletion at the beginning take O(1) time.

  • A Singly Linked List moves forward only; it does not provide direct backward traversal.
