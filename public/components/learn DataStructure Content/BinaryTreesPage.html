Binary Trees

Learn how Binary Trees organize data using nodes with at most two children, and explore their structure, types, traversal methods, and practical applications.

Previous Next
Introduction

What Is a Binary Tree?

A Binary Tree is a non-linear data structure in which each node can have at most two children: a left child and a right child.

Binary Trees are commonly used to represent hierarchical relationships and organize data efficiently. They are also the foundation of structures such as Binary Search Trees and Heaps.

Key Idea: Each node in a Binary Tree can have zero, one, or two children, but never more than two.
Structure

Binary Tree Structure

  • Root: Node A is the starting point of the tree.
  • Left Child: Node B is the left child of A.
  • Right Child: Node C is the right child of A.
  • Leaf Nodes: Nodes D, E, and F have no children.
Terminology

Binary Tree Terminology

Understanding these terms will help you work with Binary Trees and their algorithms.

Root

The topmost node in the tree, which has no parent.

Parent

A node that has one or more children.

Child

A node directly connected below another node.

Leaf Node

A node that has no children.

Subtree

A node together with all its descendants.

Height

The number of edges on the longest downward path from a node to a leaf. The height of a tree is the height of its root.

Depth

The number of edges from the root to a particular node.

Properties

Binary Tree Properties

  • Each node can have at most two children.
  • Each node can have a left child, a right child, both children, or no children.
  • The maximum number of nodes at level \(L\), when the root is at level 0, is \(2^L\).
  • The maximum number of nodes in a Binary Tree of height \(H\), measured in edges, is \(2^{H+1} - 1\).
  • A non-empty tree with \(N\) nodes has exactly \(N - 1\) edges.
Remember: These maximum-node formulas describe a completely filled Binary Tree through the specified level or height.
Types

Types of Binary Trees

Binary Trees can be classified according to how their nodes and levels are arranged.

Full Binary Tree

Every node has either zero or exactly two children.

Complete Binary Tree

Every level is completely filled except possibly the last level, and the last level is filled from left to right.

Perfect Binary Tree

Every internal node has exactly two children, and all leaf nodes are at the same level.

Balanced Binary Tree

A tree whose subtree heights remain within a defined balance condition. The exact condition depends on the type of balanced tree.

Skewed Binary Tree

A tree in which each internal node has only one child, forming a structure similar to a linked list.

Traversal

Binary Tree Traversal

Traversal is the process of visiting every node in a tree in a specific order.

Preorder Traversal

Visit the root, traverse the left subtree, then traverse the right subtree.

Order: Root → Left → Right

Inorder Traversal

Traverse the left subtree, visit the root, then traverse the right subtree.

Order: Left → Root → Right

Postorder Traversal

Traverse the left subtree, traverse the right subtree, then visit the root.

Order: Left → Right → Root

Level Order Traversal

Visit nodes level by level, from left to right. This traversal is commonly implemented using a Queue.

Important: Preorder, Inorder, and Postorder are depth-first traversal methods. Level Order is a breadth-first traversal method.
Applications

Applications of Binary Trees

  • Representing hierarchical data.
  • Building Binary Search Trees for searching and organizing data.
  • Implementing Heaps used in priority queues.
  • Representing expressions using expression trees.
  • Supporting decision-making processes through decision trees.
Summary

Key Takeaways

  • A Binary Tree is a non-linear data structure in which each node has at most two children.
  • The two possible child positions are the left child and the right child.
  • Full, Complete, Perfect, Balanced, and Skewed Binary Trees describe different structural properties.
  • Preorder, Inorder, Postorder, and Level Order are common ways to traverse a Binary Tree.
  • Binary Trees are the foundation of several important data structures and algorithms.
