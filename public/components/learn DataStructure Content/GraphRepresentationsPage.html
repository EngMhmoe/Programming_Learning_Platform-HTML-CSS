Graph Representations

Learn how graphs are stored in memory using adjacency matrices and adjacency lists, and understand how to choose the right representation for different problems.

Previous Next
01
Introduction

What Are Graph Representations?

A graph representation is a way to store a graph's vertices and edges in computer memory.

A graph consists of vertices and edges, but a computer needs a specific data structure to store this information. Two common approaches are the Adjacency Matrix and the Adjacency List.

Both representations can describe the same graph, but they differ in memory usage and in how efficiently they support operations such as checking connections and listing neighbors.

Example Graph

Consider an undirected graph with four vertices and these connections: A–B, A–C, B–C, and C–D.

Vertices: A, B, C, D Edges: A–B, A–C, B–C, C–D
02
Representation One

Adjacency Matrix

An adjacency matrix uses a two-dimensional array to indicate which vertices are connected.

For a graph containing V vertices, an adjacency matrix has V rows and V columns. Each cell indicates whether an edge exists between the corresponding pair of vertices.

  • 1 means an edge exists.
  • 0 means no edge exists.
  • For an undirected graph, the matrix is symmetric.

Adjacency Matrix Example

Using the graph from the previous section, its adjacency matrix is:

A B C D
A 0 1 1 0
B 1 0 1 0
C 1 1 0 1
D 0 0 1 0

The value at row A and column B is 1 because A is connected to B. The value at row A and column D is 0 because no direct edge connects them.

JavaScript Example Adjacency Matrix 
const matrix = [
    [0, 1, 1, 0],
    [1, 0, 1, 0],
    [1, 1, 0, 1],
    [0, 0, 1, 0]
];

// Check whether A is connected to B
console.log(matrix[0][1]); // 1

// Check whether A is connected to D
console.log(matrix[0][3]); // 0

Advantages

  • Checking whether an edge exists takes O(1) time.
  • Simple to implement using a two-dimensional array.
  • Useful for dense graphs with many edges.

Disadvantages

  • Requires O(V²) space.
  • Can waste memory when the graph has few edges.
  • Listing all neighbors of a vertex takes O(V) time.
03
Representation Two

Adjacency List

An adjacency list stores each vertex alongside a collection of its neighboring vertices.

Instead of allocating a cell for every possible pair of vertices, an adjacency list stores only the neighbors connected to each vertex.

This makes it especially useful for sparse graphs, where the number of edges is relatively small compared with the number of possible edges.

Adjacency List Example

A
B C
B

C
A B D
D

JavaScript Example Adjacency List 
const graph = {
    A: ["B", "C"],
    B: ["A", "C"],
    C: ["A", "B", "D"],
    D: ["C"]
};

// Get the neighbors of A
console.log(graph.A); // ["B", "C"]

// Check the neighbors of C
console.log(graph.C); // ["A", "B", "D"]

Advantages

  • Uses O(V + E) space.
  • Efficient for iterating over a vertex's neighbors.
  • Usually a good choice for sparse graphs.

Disadvantages

  • Checking for a specific edge can take O(degree(V)) time.
  • Requires managing a collection of neighbors for each vertex.
04
Comparison

Adjacency Matrix vs Adjacency List

Both approaches represent the same graph, but each has different performance and memory characteristics.

Operation / Feature Adjacency Matrix Adjacency List
Space Complexity O(V²) O(V + E)
Check an Edge O(1) O(degree(V))
Iterate over Neighbors O(V) O(degree(V))
Add a Vertex Usually O(V²) to resize and rebuild O(1) amortized with a suitable structure
Best Suited For Dense Graphs Sparse Graphs

Here, V is the number of vertices, E is the number of edges, and degree(V) means the number of neighbors of the specific vertex being examined. Exact costs can vary with the implementation and graph type.

05
Practical Decisions

When Should You Use Each Representation?

Choose a representation according to the graph's density and the operations your application performs most.

Choose an Adjacency Matrix When

  • The graph is dense.
  • You frequently check whether a particular edge exists.
  • The number of vertices is relatively small or predictable.
  • Simple, constant-time edge lookup is important.

Choose an Adjacency List When

  • The graph is sparse.
  • You want to reduce memory usage.
  • You frequently traverse a vertex's neighbors.
  • The graph contains many vertices with few connections.

Summary

Key Takeaways

Review the main differences before moving to the next topic.

  • Graph representations define how vertices and edges are stored in computer memory.
  • An adjacency matrix stores edge information in a two-dimensional array and uses O(V²) space.
  • An adjacency list stores each vertex's neighbors and uses O(V + E) space.
  • An adjacency matrix checks for an edge in O(1) time.
  • An adjacency list is often more memory-efficient for sparse graphs.
  • The best representation depends on graph density and the operations your application needs.
Learning Note

Make sure you can convert a small graph into both an adjacency matrix and an adjacency list. Pay special attention to the difference between O(V²) and O(V + E) space complexity.
