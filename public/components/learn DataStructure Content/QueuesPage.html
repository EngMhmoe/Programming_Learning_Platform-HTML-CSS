01

Introduction to Queues

Understand the basic idea behind a Queue.

What Is a Queue?

A Queue is a linear data structure that stores elements in a specific order. The first element added to the Queue is the first element removed.

Think about people waiting in line to buy tickets. The person who arrives first is served first, while new people join the end of the line.

Key Concept: FIFO

FIFO stands for First In, First Out. The first element inserted into the Queue is the first element removed from it.

Real-Life Example: A Ticket Line

👤 Person 1
👤 Person 2
👤 Person 3
New people join here First person served here

Remember: A Queue adds elements at the Rear and removes elements from the Front.

02

Why Do We Use Queues?

Discover where Queues are useful.

Queues help us process tasks in the same order they arrive. They are useful whenever fairness and order matter.

Print Jobs

Documents can wait in a Queue and print in the order they were submitted.

Customer Support

Requests can be handled in the order they arrive.

Task Scheduling

Systems can manage waiting tasks before processing them.

Breadth-First Search

Graph and tree algorithms use Queues to visit nearby nodes first.

03

Structure of a Queue

Learn about Front, Rear, and stored elements.

A Queue contains elements arranged in order. Two important positions help us manage it:

Front

The position of the first element, which is removed first.

Rear

The position where new elements are added.

Front Rear
10
20
30
First to leave Last to enter

Example Using an Array

In JavaScript, we can use an array to represent a simple Queue: 

const queue = [10, 20, 30];

console.log(queue);
// [10, 20, 30]

console.log(queue[0]);
// 10 (Front)

console.log(queue[queue.length - 1]);
// 30 (Rear)

In this example, the first element is at index 0, and the last element is at index queue.length - 1.

04

The FIFO Principle

First In, First Out.

FIFO means the first element added to the Queue is the first element removed from it.

Enqueue

Add an element

A new element is inserted at the Rear of the Queue. 

queue.push(40);

Dequeue

Remove an element

The element at the Front is removed first. 

queue.shift();

Step-by-Step Example

Start with an empty Queue and add three elements:

const queue = [];

queue.push(10);
queue.push(20);
queue.push(30);

console.log(queue);
// [10, 20, 30]

Now remove one element from the Front:

const removed = queue.shift();

console.log(removed);
// 10

console.log(queue);
// [20, 30]

Result: The value 10 leaves first because it was added first.

05

Basic Queue Operations

Understand the most common Queue operations.

1. Enqueue

Adds a new element to the Rear of the Queue. 

queue.push(40);

2. Dequeue

Removes and returns the element at the Front. 

const first = queue.shift();

3. Peek

Returns the Front element without removing it. 

const first = queue[0];

4. isEmpty

Checks whether the Queue contains no elements. 

const empty = queue.length === 0;

5. Size

Returns the number of elements currently stored. 

const count = queue.length;

These examples use JavaScript arrays. The shift() method is easy to understand, but removing the first array element may take O(n) time because remaining elements may need to be shifted.

06

Implementing a Queue in JavaScript

Create a Queue class with the basic operations.

We can create a Queue class to organize the Queue operations in one place. 

class Queue {
    constructor() {
        this.items = [];
    }

    // Add an element to the Rear
    enqueue(element) {
        this.items.push(element);
    }

    // Remove and return the Front element
    dequeue() {
        if (this.isEmpty()) {
            return undefined;
        }

        return this.items.shift();
    }

    // Return the Front element without removing it
    peek() {
        if (this.isEmpty()) {
            return undefined;
        }

        return this.items[0];
    }

    // Check whether the Queue is empty
    isEmpty() {
        return this.items.length === 0;
    }

    // Return the number of elements
    size() {
        return this.items.length;
    }

    // Display the Queue elements
    print() {
        console.log(this.items);
    }
}

Using the Queue Class

const queue = new Queue();

queue.enqueue(10);
queue.enqueue(20);
queue.enqueue(30);

queue.print();
// [10, 20, 30]

console.log(queue.peek());
// 10

console.log(queue.dequeue());
// 10

queue.print();
// [20, 30]

console.log(queue.size());
// 2

console.log(queue.isEmpty());
// false

How Does It Work?

  • constructor(): Creates an empty array to store the elements.
  • enqueue(element): Adds an element to the end of the array.
  • dequeue(): Removes and returns the first element, or undefined if the Queue is empty.
  • peek(): Reads the first element without removing it.
  • isEmpty(): Returns true if the Queue is empty.
  • size(): Returns the number of stored elements.
07

Stack vs Queue

Understand the difference between these structures.

Both Stack and Queue store multiple elements, but they remove elements in different orders.

Feature Stack Queue
Principle LIFO FIFO
Full Form Last In, First Out First In, First Out
Add Operation Push Enqueue
Remove Operation Pop Dequeue
Common Example Stack of plates People waiting in line

Stack

The last element added is the first element removed.

Push → Push → Pop

Queue

The first element added is the first element removed.

Enqueue → Enqueue → Dequeue

Queue Time Complexity

Understand how operation costs are measured.

Time complexity describes how the time required by an operation changes as the number of elements grows.

Operation Array with shift() Queue with Front Index
Enqueue O(1)* O(1)
Dequeue O(n) O(1)
Peek O(1) O(1)
isEmpty O(1) O(1)

* Array insertion at the end is generally amortized O(1). Resizing can occasionally take longer. A Queue implemented with a Front Index avoids shifting every remaining element during dequeue.

O(1)

Constant Time

The operation takes approximately constant time as the Queue grows.

O(n)

Linear Time

The operation may need to process or move a number of elements proportional to the Queue size.

09

Advantages and Disadvantages

Know when a Queue is the right choice.

Advantages

  • Maintains the order in which elements arrive.
  • Useful for scheduling and task processing.
  • Supports a clear and simple processing flow.
  • Works well for breadth-first search algorithms.

Disadvantages

  • Does not directly provide priority-based ordering.
  • Searching for a particular element can take O(n).
  • Using array shift() may be inefficient for large Queues.
  • Some implementations need extra logic to manage memory or reuse array positions.
10

Key Takeaways

Review the most important concepts.

A Queue is a linear data structure that follows the FIFO principle.

Enqueue adds an element to the Rear.

Dequeue removes the element at the Front.

Peek reads the first element without removing it.

Using shift() is simple, but an implementation with a Front Index can make dequeue more efficient.
