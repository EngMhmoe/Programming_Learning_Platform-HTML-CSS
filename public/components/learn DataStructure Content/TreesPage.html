01

Introduction to Trees

Understand the basic idea behind a Tree.

What Is a Tree?

A Tree is a non-linear data structure that organizes data in a hierarchical relationship. It consists of nodes connected by edges, starting from a special node called the root.

Unlike arrays and linked lists, which organize elements in a sequence, a Tree allows one node to connect to multiple child nodes.

Hierarchical

Data is arranged in levels, from the root down to its descendants.

Connected Nodes

Nodes are connected through edges that represent relationships.

Real-World Structure

Trees can represent folders, organization charts, and hierarchical categories.

A tree is a non-linear structure because a node can connect to multiple child nodes instead of storing all elements in one straight sequence.

03

Tree Terminology

Learn the essential terms used when working with Trees.

Root

The topmost node of a tree. It has no parent.

Parent

A node that has one or more child nodes.

Child

A node directly connected below another node.

Leaf

A node that has no children.

Edge

A connection between two nodes.

Level

The position of a node relative to the root.

Subtree

A node together with all its descendants.

Height

The number of edges on the longest downward path from a node to a leaf.

04

Properties of Trees

Understand the fundamental properties of a Tree.

  • A non-empty tree has exactly one root node.
  • Every node except the root has exactly one parent in a standard rooted tree.
  • A tree is connected and contains no cycles.
  • A node can have zero or more children, depending on the type of tree.
  • A tree with N nodes has N - 1 edges.
Tree Example JavaScript 
const tree = {
    value: "A",
    children: [
        {
            value: "B",
            children: [
                { value: "D", children: [] },
                { value: "E", children: [] }
            ]
        },
        {
            value: "C",
            children: [
                { value: "F", children: [] },
                { value: "G", children: [] }
            ]
        }
    ]
};

console.log(tree.value); // A

This example represents a simple tree using nested JavaScript objects. Each node stores a value and an array of children.

Preorder Traversal JavaScript 
function preorder(node) {
    if (node === null) {
        return;
    }

    console.log(node.value);

    for (const child of node.children) {
        preorder(child);
    }
}

The function visits the current node first and then recursively visits each child. This example assumes each node contains a value and a children array.

08

Key Takeaways

Review the most important concepts.

  • A Tree is a non-linear data structure.
  • The root is the topmost node.
  • Parent-child relationships form the tree hierarchy.
  • Leaf nodes have no children.
  • Tree traversal defines the order in which nodes are visited.
  • Binary Trees, BSTs, and Heaps are specialized tree structures.
