Data Structure Programming

Dictionaries

Learn how dictionaries organize information using key-value pairs, support efficient lookup and updates, and can be implemented using different data structures.

Previous Next
Definition

What Is a Dictionary?

A dictionary is an abstract data type that stores information as key-value pairs. Each key identifies an entry and is used to access its associated value.

Key-Value Pairs

A key identifies an entry, while a value contains the information associated with that key.

Key "username"
Value "alex"

For example, a dictionary can store student IDs as keys and student names as values.

Key Value
101 Mohamed
102 Sara
103 Omar
Remember

A dictionary accesses values through their keys. A key is an identifier, not necessarily a numeric position like an array index.

Main Concept

How Does a Dictionary Work?

A lookup starts with a key and returns the value associated with that key, if the entry exists.

01

Provide a Key

Specify the identifier of the entry you want.

"username"
02

Find the Entry

The implementation searches for the matching key.

get(key)
03

Return the Value

The matching value is returned to the caller.

"alex"
Important

The dictionary defines the operations available to the user. Its implementation determines how those operations locate and manage entries.

Operations

Common Dictionary Operations

Dictionaries provide operations for adding, retrieving, updating, and removing key-value pairs.

Insert

Add a key and its associated value.

insert(key, value)

Lookup

Retrieve a value using its key.

get(key)

Update

Change the value associated with an existing key.

update(key, value)

Delete

Remove an entry identified by its key.

remove(key)

Check Key

Determine whether a key exists in the dictionary.

containsKey(key)

Get Entries

Access the dictionary's keys, values, or entries.

entries()
Note

These operation names describe common dictionary behavior. The actual method names depend on the programming language and implementation.

Code Example

Dictionary Example in JavaScript

JavaScript's built-in Map type provides a convenient way to store and retrieve key-value pairs.

JavaScript
Map 
const student = new Map();

// Insert entries
student.set("name", "Mohamed");
student.set("age", 20);
student.set("major", "Computer Science");

// Look up a value
console.log(student.get("name"));

// Check whether a key exists
console.log(student.has("age"));

// Update a value
student.set("age", 21);

// Remove an entry
student.delete("major");

console.log(student.get("age"));
console.log(student.size);
Expected Output 
Mohamed
true
21
2
Why Use Map?

Map supports methods such as set(), get(), has(), and delete(). It also supports keys of different types and provides a size property.

Key Difference

Dictionary vs Hash Table

A dictionary describes the behavior of key-value storage, while a hash table is one possible way to implement that behavior.

Dictionary

Abstract Data Type

Defines the operations used to manage key-value pairs.

  • Defines supported operations
  • Focuses on expected behavior
  • Can have different implementations

Hash Table

Data Structure

Uses a hash function to map keys to positions in a table.

  • Uses a hash function
  • Must handle collisions
  • Usually provides fast average lookup
Remember the Difference

A hash table can implement a dictionary. However, a dictionary can also be implemented using other data structures, such as a balanced search tree.

Performance

Dictionary Time Complexity

The performance of dictionary operations depends on the data structure used to implement them.

Operation Average Case Worst Case
Lookup O(1) O(n)
Insertion O(1) O(n)
Deletion O(1) O(n)
Complexity Note

These values describe a typical hash-table-based implementation. Actual performance depends on hashing, collisions, resizing, and implementation details. Other dictionary implementations have different complexity guarantees.

Evaluation

Benefits and Limitations

Dictionaries are useful whenever data needs to be accessed through meaningful identifiers.

Benefits

  • Fast average lookup in hash-based implementations.
  • Clear organization of key-value information.
  • Convenient insertion, updating, and deletion.
  • Useful for records, mappings, and configuration data.

Limitations

  • Keys must follow the implementation's equality rules.
  • Hash-based implementations must handle collisions.
  • Extra memory may be needed for efficient lookup.
  • Ordering behavior depends on the implementation.
Summary

Key Takeaways

Review the most important ideas before moving to the next lesson.

A dictionary stores information as key-value pairs.

A key identifies an entry and provides access to its associated value.

Common operations include lookup, insertion, updating, deletion, and checking for a key.

A hash table is one possible implementation of a dictionary, not the definition of a dictionary itself.

Quick Reminder

Dictionary = What key-value operations are available? Hash Table = One way to implement those operations.
