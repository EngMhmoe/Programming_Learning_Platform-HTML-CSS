Doubly Linked List

Learn how Doubly Linked Lists work, how each node connects to both the next and previous nodes, and how to traverse the list in both directions.

Previous Next
Introduction

What Is a Doubly Linked List?

A Doubly Linked List is a linear data structure made up of nodes connected in both directions.

Each node stores three main parts:

  • Previous: A reference to the previous node.
  • Data: The value stored inside the node.
  • Next: A reference to the next node.

The first node's prev reference is usually null, and the last node's next reference is also null.

Remember

A Doubly Linked List can move forward and backward because each node stores two links.

Node Structure

How Does a Node Work?

Every node contains data and two references that connect it to its neighboring nodes.

prev data next
Previous Node Stored Value Next Node

For example, if a node stores the value 20, its prev reference may point to the node containing 10, while its next reference may point to the node containing 30.

Node Structure JavaScript 
class Node {
    constructor(data) {
        this.data = data;
        this.prev = null;
        this.next = null;
    }
}

const node = new Node(20);

console.log(node.data); // 20
console.log(node.prev); // null
console.log(node.next); // null
Note

The prev and next properties initially contain null because the new node is not connected to other nodes yet.

Connections

How Are Nodes Connected?

Each node connects to its neighbors using both prev and next.

HEAD
prev 10 next
prev 20 next
prev 30 next
TAIL
  • Head: Points to the first node.
  • Tail: Points to the last node when the implementation maintains a tail reference.
  • Forward traversal: Follow the next reference.
  • Backward traversal: Follow the prev reference.
Implementation

Creating a Doubly Linked List

Let's create three nodes and connect them to form a Doubly Linked List.

Creating Nodes JavaScript 
class Node {
    constructor(data) {
        this.data = data;
        this.prev = null;
        this.next = null;
    }
}

const first = new Node(10);
const second = new Node(20);
const third = new Node(30);

// Connect the first and second nodes
first.next = second;
second.prev = first;

// Connect the second and third nodes
second.next = third;
third.prev = second;

console.log(first.data);        // 10
console.log(first.next.data);   // 20
console.log(second.prev.data);  // 10
console.log(second.next.data);  // 30
console.log(third.prev.data);   // 20
Important

When connecting two neighboring nodes, update both references: the first node's next and the second node's prev.

Traversal

Forward Traversal

Forward traversal visits nodes from the first node to the last node using next.

Forward Traversal JavaScript 
function printForward(head) {
    let current = head;

    while (current !== null) {
        console.log(current.data);
        current = current.next;
    }
}

The function starts at head, prints the current node's data, and moves to the next node. It stops when current becomes null.

Example Output 
10
20
30
Reverse Traversal

Backward Traversal

Backward traversal visits nodes from the last node to the first node using prev.

Backward Traversal JavaScript 
function printBackward(tail) {
    let current = tail;

    while (current !== null) {
        console.log(current.data);
        current = current.prev;
    }
}

This time, the function starts at tail and follows each node's prev reference until it reaches null.

Example Output 
30
20
10
Operations

Common Doubly Linked List Operations

A Doubly Linked List supports several common operations for managing its nodes.

Insertion

Add a new node at the beginning, end, or a specific position.

Deletion

Remove a node and update the neighboring nodes' references.

Searching

Find a node by checking its stored value.

Traversal

Visit the nodes in forward or backward order.

Remember

Insertion and deletion can be efficient when the target node is already known, because neighboring references can be updated directly. Finding that node may still require traversal.

Pros & Cons

Advantages and Disadvantages

Doubly Linked Lists offer more flexible traversal, but they also require additional memory.

Advantages

  • Supports forward and backward traversal.
  • Can remove a known node efficiently when references are maintained.
  • Useful for navigation in both directions.

Disadvantages

  • Requires extra memory for the prev reference.
  • Operations must maintain two references correctly.
  • More complex to implement than a Singly Linked List.
Comparison

Singly vs. Doubly Linked List

The main difference is the number of references each node stores and the directions in which the list can be traversed.

Feature Singly Linked List Doubly Linked List
Node references One: next Two: prev and next
Traversal Forward only Forward and backward
Memory usage Usually lower Usually higher
Reverse traversal Requires extra work or a different approach Can follow prev
Implementation Simpler Requires maintaining two links
Performance

Time Complexity

The performance of an operation depends on whether the target node is already known or must be searched for.

Operation Typical Time Complexity
Access by position O(n)
Search for a value O(n)
Insert at the beginning O(1)
Insert at the end with a tail reference O(1)
Remove a known node O(1)
Complexity Note

These values assume the list maintains the required references, such as head and tail. Finding a node by value or position still takes O(n) time.

Summary

Key Takeaways

Review the most important points about Doubly Linked Lists.

  • A Doubly Linked List consists of connected nodes.
  • Each node stores data, a prev reference, and a next reference.
  • The first node's prev and the last node's next are usually null.
  • Traversal is possible in both directions.
  • The extra reference uses more memory but makes some operations more flexible.
