Circular Queue

Learn how Circular Queues reuse memory efficiently, understand circular array indexing, and implement Circular Queue operations using JavaScript.

Introduction

What Is a Circular Queue?

A Circular Queue is a special type of Queue in which the last position connects back to the first position, allowing available array positions to be reused.

Key Concept: Circular Movement

Like a regular Queue, a Circular Queue follows the FIFO (First In, First Out) principle. However, its indexes can wrap around to the beginning of the array.

Remember

A Circular Queue is still a Queue. It follows FIFO, but its positions can be reused in a circular manner.

Main Concept

Why Do We Need a Circular Queue?

Understand the limitations of a simple array-based Queue and how circular indexing helps reuse positions.

The Problem with a Simple Array Queue

Imagine a Queue implemented using an array with five positions. We insert five elements, then remove the first three elements. 

const queue = [10, 20, 30, 40, 50];

queue.shift();
queue.shift();
queue.shift();

console.log(queue);
// [40, 50]

The first three positions become available after removing their elements. A fixed-size Queue that only advances its Rear index may fail to reuse those positions without additional logic.

Benefits of a Circular Queue

Reuse Positions

Reuses available positions instead of leaving them unused behind the Front.

Efficient Operations

Enqueue and Dequeue can run in O(1) time in a properly implemented fixed-size Queue.

Fixed Memory

Uses a predefined number of array positions when implemented with fixed capacity.

Core Concept

Circular Indexing

Learn how the modulo operator allows an index to return to the beginning of an array.

Instead of increasing an index indefinitely, we use the modulo operator % to wrap it around when it reaches the array length.

Circular Index Formula

(currentIndex + 1) % capacity

Understanding the Modulo Operator 

console.log(1 % 5); // 1
console.log(2 % 5); // 2
console.log(3 % 5); // 3
console.log(4 % 5); // 4
console.log(5 % 5); // 0

When the next index reaches 5 and the capacity is 5, the result becomes 0. This returns the index to the first position.

Operations

Basic Circular Queue Operations

Explore the main operations used to manage a Circular Queue.

01

Enqueue

Adds a new element to the Rear. The insertion position wraps around when necessary. 

rear = (front + size) % capacity;
02

Dequeue

Removes the Front element and advances Front to the next circular position. 

front = (front + 1) % capacity;
03

Peek

Returns the Front element without removing it. 

return items[front];
04

isEmpty

Checks whether the Queue contains no elements. 

return size === 0;
05

isFull

Checks whether the Queue has reached its maximum capacity. 

return size === capacity;
Operation 01

Enqueue Operation

Learn how to insert an element into a Circular Queue.

01

Check Capacity

Check whether the Queue is full.

02

Calculate Rear

Calculate the insertion index using (front + size) % capacity.

03

Insert Element

Store the new element at the calculated index.

04

Update Size

Increase Size by one.

enqueue(element) {
    if (this.isFull()) {
        return false;
    }

    const rear = (this.front + this.size) % this.capacity;

    this.items[rear] = element;
    this.size++;

    return true;
}
Important

The formula (front + size) % capacity calculates the position where the next element should be inserted.

Operation 02

Dequeue Operation

Learn how to remove the first element without shifting the remaining elements.

01

Check Queue State

Check whether the Queue is empty.

02

Save the Front Element

Read and save the element at the Front index.

03

Advance Front

Move Front using (front + 1) % capacity.

04

Update Size

Decrease Size and return the removed element.

dequeue() {
    if (this.isEmpty()) {
        return undefined;
    }

    const removedElement = this.items[this.front];

    this.items[this.front] = undefined;
    this.front = (this.front + 1) % this.capacity;

    this.size--;

    return removedElement;
}
Important

Dequeue moves the Front index instead of shifting all the remaining elements. This allows the operation to run in O(1) time.

Implementation

Implementing Circular Queue in JavaScript

Combine the previous operations into a reusable JavaScript class. 

class CircularQueue {
    constructor(capacity) {
        if (!Number.isInteger(capacity) || capacity <= 0) {
            throw new Error("Capacity must be a positive integer.");
        }

        this.items = new Array(capacity);
        this.capacity = capacity;
        this.front = 0;
        this.size = 0;
    }

    // Check whether the Queue is empty
    isEmpty() {
        return this.size === 0;
    }

    // Check whether the Queue is full
    isFull() {
        return this.size === this.capacity;
    }

    // Return the current number of elements
    getSize() {
        return this.size;
    }

    // Add an element to the Rear
    enqueue(element) {
        if (this.isFull()) {
            return false;
        }

        const rear = (this.front + this.size) % this.capacity;

        this.items[rear] = element;
        this.size++;

        return true;
    }

    // Remove and return the Front element
    dequeue() {
        if (this.isEmpty()) {
            return undefined;
        }

        const removedElement = this.items[this.front];

        this.items[this.front] = undefined;
        this.front = (this.front + 1) % this.capacity;

        this.size--;

        return removedElement;
    }

    // Return the Front element without removing it
    peek() {
        if (this.isEmpty()) {
            return undefined;
        }

        return this.items[this.front];
    }

    // Return the Queue elements in FIFO order
    toArray() {
        const result = [];

        for (let i = 0; i < this.size; i++) {
            const index = (this.front + i) % this.capacity;
            result.push(this.items[index]);
        }

        return result;
    }

    // Display the Queue elements
    print() {
        console.log(this.toArray());
    }
}

Using the Circular Queue Class 

const queue = new CircularQueue(3);

queue.enqueue(10);
queue.enqueue(20);
queue.enqueue(30);

queue.print();
// [10, 20, 30]

console.log(queue.isFull());
// true

console.log(queue.dequeue());
// 10

queue.enqueue(40);

queue.print();
// [20, 30, 40]

console.log(queue.peek());
// 20

console.log(queue.getSize());
// 3
new CircularQueue(3) Creates a Queue with three available positions.
enqueue() Adds elements until the Queue becomes full.
dequeue() Removes 10 and advances Front.
toArray() Returns elements in FIFO order, even after wraparound.
Key Observation

After removing 10, inserting 40 reuses the available array position. The logical Queue order becomes [20, 30, 40].

Comparison

Circular Queue vs Linear Queue

Compare how both Queue implementations manage their array positions.

Linear Queue

Linear Movement
  • Positions are arranged in a line.
  • A simple fixed-array implementation may leave earlier positions unused.
  • Extra logic may be needed to reuse freed positions.

Circular Queue

Circular Movement
  • The last position wraps around to the first.
  • Freed positions can be reused.
  • Front and Rear move using circular indexing.
Important Difference

A Circular Queue does not need to shift all remaining elements after Dequeue. Both approaches can be implemented efficiently, but circular indexing makes fixed-array position reuse easier.

Performance

Circular Queue Time Complexity

Understand the time complexity of the main operations.

01

Enqueue

O(1) — calculates an index and stores one element.

02

Dequeue

O(1) — reads one element and advances Front.

03

Peek

O(1) — accesses the Front element directly.

04

isEmpty and isFull

O(1) — compare Size with zero or Capacity.

05

toArray

O(n) — visits every element to create a new array.

O(1)

The main Queue operations take constant time.

O(n)

Converting all Queue elements into a new array requires visiting each element.

Applications

Applications of Circular Queue

Discover where Circular Queues and circular buffers are useful in real-world applications.

Buffer Management

Stores incoming and outgoing data while reusing available memory positions.

Round-Robin Scheduling

Helps process tasks in rotation, returning unfinished tasks to the end of the cycle.

Streaming Data

Temporarily stores incoming audio and other streaming data.

Embedded Systems

Provides predictable memory usage in resource-constrained systems.

Pros & Cons

Advantages and Disadvantages

Review the strengths and limitations of a Circular Queue.

Advantages

  • Reuses empty positions in a fixed array.
  • Supports O(1) Enqueue and Dequeue.
  • Avoids shifting elements during removal.
  • Works well for fixed-size buffers.
  • Supports repeated scheduling cycles.

Disadvantages

  • Index calculations require careful implementation.
  • A fixed-capacity Queue cannot accept elements when full.
  • Empty and full states must be handled correctly.
  • Resizing requires additional logic if capacity must grow.
Summary

Key Takeaways

Review the most important concepts before moving to the next lesson.

A Circular Queue follows the FIFO principle.

The last array position connects logically back to the first position.

The modulo operator % is used to calculate circular indexes.

Front, Size, and Capacity help manage the Queue's state.

Enqueue, Dequeue, Peek, isEmpty, and isFull run in O(1) time in this implementation.

Quick Reminder

Use (index + 1) % capacity whenever an index needs to move forward and wrap around at the end of the array.
