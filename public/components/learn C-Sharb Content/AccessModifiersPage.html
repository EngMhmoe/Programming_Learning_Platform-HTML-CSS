Learn how access modifiers control the visibility of classes, fields, methods, and properties in C#.

Access Modifiers

Access Modifiers

Access modifiers are used to set the access level and visibility of classes, fields, methods, and properties.

By now, you are quite familiar with the public keyword that appears in many of our examples:

Example 
public string color;

The public keyword is an access modifier, which is used to set the access level and visibility for classes, fields, methods, and properties.

C# has the following access modifiers:

Modifier Description
public The code is accessible from all classes.
private The code is only accessible within the same class.
protected The code is accessible within the same class, or in a class that is inherited from that class.
internal The code is accessible within its own assembly, but not from another assembly.

There are also two combinations: protected internal and private protected .

For now, let's focus on the public and private modifiers.

Private

Private Modifier

A private member can only be accessed from within the same class.

If you declare a field with the private access modifier, it can only be accessed within the same class.

Example 
class Car
{
    private string model = "Mustang";

    static void Main(string[] args)
    {
        Car myObj = new Car();

        Console.WriteLine(myObj.model);
    }
}

The output will be:

Mustang

If you try to access the private field outside the class, an error will occur.

Example 
class Car
{
    private string model = "Mustang";
}

class Program
{
    static void Main(string[] args)
    {
        Car myObj = new Car();

        Console.WriteLine(myObj.model);
    }
}
Result:

Car.model is inaccessible because model is private and can only be accessed inside the Car class.

Public

Public Modifier

A public member can be accessed from other classes.

If you declare a field with the public access modifier, it is accessible from other classes.

Example 
class Car
{
    public string model = "Mustang";
}

class Program
{
    static void Main(string[] args)
    {
        Car myObj = new Car();

        Console.WriteLine(myObj.model);
    }
}

The output will be:

Mustang
Why Access Modifiers?

Access modifiers control the visibility of class members and help you control how different parts of your program interact with each other.

They also help achieve encapsulation, which means hiding sensitive data and exposing only what is necessary.

Default Access

Default Access Modifier

Class members are private by default when no access modifier is specified.

By default, class members are private if you don't specify an access modifier.

Example 
class Car
{
    string model; // private
    string year;  // private
}
Remember:

If you do not specify an access modifier for a class member, its default access level is private.
