C# Abstraction

Learn how abstraction works in C# using abstract classes and methods to hide implementation details and expose only essential functionality.

Previous Next
Abstraction

What is Abstraction?

Data abstraction is the process of hiding certain details and showing only essential information to the user.

Abstraction can be achieved with either abstract classes or interfaces.

The abstract keyword is used for classes and methods that are intended to be used as a base for other classes.

Abstract Class

Abstract Class

An abstract class is a restricted class that cannot be used to create objects directly.

To create an abstract class, use the abstract keyword.

C# Example 
abstract class Animal
{
    public abstract void AnimalSound();

    public void Sleep()
    {
        Console.WriteLine("Zzz");
    }
}

Example Explained

The Animal class is declared as abstract, which means it is intended to be used as a base class.

The AnimalSound() method is also abstract, so derived classes must provide their own implementation of this method.

The Sleep() method is a regular method and already has an implementation that can be inherited by derived classes.

Important

Cannot Create an Object

You cannot create an object directly from an abstract class. Trying to create an object from an abstract class results in a compiler error.

C# Example 
Animal myObj = new Animal();

// Error: Cannot create an instance of the abstract class or interface 'Animal'
Compiler Error Cannot create an instance of the abstract class or interface 'Animal'
Inheritance

Inherit an Abstract Class

An abstract class can be inherited by another class. The derived class must provide implementations for all abstract methods.

C# Example 
// Abstract class
abstract class Animal
{
    // Abstract method
    public abstract void AnimalSound();

    // Regular method
    public void Sleep()
    {
        Console.WriteLine("Zzz");
    }
}


// Derived class
class Pig : Animal
{
    public override void AnimalSound()
    {
        // The body of AnimalSound() is provided here
        Console.WriteLine("The pig says: wee wee");
    }
}


class Program
{
    static void Main(string[] args)
    {
        Pig myPig = new Pig();

        myPig.AnimalSound();
        myPig.Sleep();
    }
}

// Outputs:
// The pig says: wee wee
// Zzz

Example Explained

The Animal class is abstract and contains the abstract AnimalSound() method.

The Pig class inherits from Animal and uses the override keyword to provide the implementation of AnimalSound().

The Sleep() method does not need to be implemented again because it already contains a method body in the abstract class.

Benefits

Why and When to Use Abstraction?

  • It hides unnecessary implementation details from users.
  • It provides a clear structure for related classes.
  • It allows derived classes to provide their own implementation of abstract methods.
  • It helps create reusable and maintainable code.
Note: An abstract class can contain both abstract methods and regular methods. Abstract methods do not have a body and must be implemented by derived classes.
