C# Loop Through an Array

Learn how to loop through arrays in C# using for and foreach loops to access each element.

Previous Next
Loop Through an Array

Using a for Loop

You can loop through the array elements with the for loop, and use the Length property to specify how many times the loop should run.

The following example outputs all elements in the cars array.

Example 
string[] cars = {
    "Volvo",
    "BMW",
    "Ford",
    "Mazda"
};

for (
    int i = 0;
    i < cars.Length;
    i++
)
{
    Console.WriteLine(cars[i]);
}
Output: Volvo, BMW, Ford, Mazda
Foreach Loop

The foreach Loop

There is also a foreach loop, which is used to loop through each element in an array.

The foreach loop is especially useful when you want to access every element without using a counter.

Syntax 
foreach (
    type variableName
    in ArrayName
)
{
    // code block to be executed
}

The following example outputs all elements in the cars array using a foreach loop.

Example 
string[] cars = {
    "Volvo",
    "BMW",
    "Ford",
    "Mazda"
};

foreach (
    string i
    in cars
)
{
    Console.WriteLine(i);
}

The example above can be read like this: for each string element, called i, in cars, print out the value of i.

If you compare the for loop and foreach loop, you will see that the foreach loop is easier to write because it does not require a counter or the Length property, and it is more readable.
