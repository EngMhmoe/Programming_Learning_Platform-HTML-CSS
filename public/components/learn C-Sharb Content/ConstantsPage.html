Constants

C# Constants

If you don't want others, or yourself, to overwrite an existing value, you can use the const keyword before the variable type.

A constant is a value that cannot be changed after it has been declared and assigned. In C#, constants are read-only values that remain the same throughout the program.

Declaration

Creating a Constant

To create a constant, place the const keyword before the data type.

Example 
const int myNum = 25 ;

Trying to Change a Constant

Once a constant has been assigned a value, you cannot assign a new value to it.

Example 
const int myNum = 25 ;
myNum = 35 ; // Error
Note: The second assignment causes an error because the value of a constant cannot be changed.
Why Constants?

When Should You Use Constants?

The const keyword is useful when a value should always remain the same.

  • Constants prevent values from being changed accidentally.
  • They make your code easier to understand by clearly identifying fixed values.
  • They are useful for values that should remain the same throughout the program.
  • A common example is the mathematical constant PI, such as 3.14159.
Important: You cannot declare a constant without assigning a value to it.
Invalid Example 
const int myNum; // Error
