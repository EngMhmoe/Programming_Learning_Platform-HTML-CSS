Operators

C# Operators

Operators are used to perform operations on variables and values.

In C#, arithmetic operators are used to perform common mathematical calculations such as addition, subtraction, multiplication, division, and more.

For example, you can use the + operator to add two values together.

Example 
int x = 200 + 50;

The value of x will be 250.

Calculations

Calculate With Variables

Arithmetic operators can also be used with variables.

You can use the result of one calculation in another calculation by storing it in a variable.

Example 
int sum1 = 200 + 50;
int sum2 = sum1 + 250;
int sum3 = sum2 + sum2;

In this example, each variable uses the value calculated by the previous variable.

Arithmetic Operators

Arithmetic Operators

C# provides several arithmetic operators for performing mathematical calculations.

Operator Name Description Example
+ Addition Adds together two values. x + y
- Subtraction Subtracts one value from another. x - y
* Multiplication Multiplies two values. x * y
/ Division Divides one value by another. x / y
% Modulus Returns the division remainder. x % y
++ Increment Increases the value of a variable by 1. x++
-- Decrement Decreases the value of a variable by 1. x--
Addition

Addition

The addition operator + adds two values together.

Example 
int result = 100 + 50;

Console.WriteLine(result);

The result of the calculation is 150.

Subtraction

Subtraction

The subtraction operator - subtracts one value from another.

Example 
int result = 100 - 50;

Console.WriteLine(result);

The result of the calculation is 50.

Multiplication

Multiplication

The multiplication operator * multiplies two values.

Example 
int result = 10 * 5;

Console.WriteLine(result);

The result of the calculation is 50.

Division

Division

The division operator / divides one value by another.

Example 
int result = 100 / 5;

Console.WriteLine(result);

The result of the calculation is 20.

Modulus

Modulus

The modulus operator % returns the remainder of a division.

Example 
int result = 10 % 3;

Console.WriteLine(result);

The result is 1 because 10 divided by 3 leaves a remainder of 1.

Increment

Increment Operator

The increment operator ++ increases the value of a variable by 1.

Example 
int x = 5;

x++;

Console.WriteLine(x);

After using x++, the value of x becomes 6.

Decrement

Decrement Operator

The decrement operator -- decreases the value of a variable by 1.

Example 
int x = 5;

x--;

Console.WriteLine(x);

After using x--, the value of x becomes 4.

Note

Arithmetic Operators

Each arithmetic operator performs a different mathematical operation.

Remember:

Use + for addition, - for subtraction, * for multiplication, / for division, and % to get the remainder.
