Introduction

What is C#?

C# is pronounced "C-Sharp".

It is an object-oriented programming language created by microsoft that runs on the .NET framework.

C# has roots from the C family, abd the language is close to other popular languages like C++ and Java.

The first version released in year 2002. The latest version, C# 13, was released released in November 2024.

C# is used for:

  • Mobile applications
  • Desktop applications
  • Web applications
  • Web services
  • Web sites
  • Games
  • VR
  • Database applications
  • And much, much more!
C# Benefits

Why Use C#?

  • It is none of the most popular programming languages in the world
  • It is easy to learn and simple to use
  • It has huge community support
  • C# is an object-oriented language which gives a clear structure yo programs and allows code to be reused, lowering development costs
  • As C3 is close to C, C++ and Java, it makes it easy for programmers to switch to C# or vice versa
