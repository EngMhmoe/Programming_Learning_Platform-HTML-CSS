C# Enums

What Are Enums?

An enum, short for enumeration, is a special type in C# that allows you to define a collection of named constants.

Instead of using numbers such as 0, 1, or 2, you can use meaningful names such as Low, Medium, and High.

Why use enums? Enums make your code more readable and help represent a fixed set of related values.
Create

Create an Enum

You can create an enum by using the enum keyword followed by the enum name and its values.

C# Example 
enum Level
{
    Low,
    Medium,
    High
}

How It Works

The enum named Level contains three named values: Low, Medium, and High.

By default, the first enum value has the numeric value 0, the second has 1, and so on.

Access

Access Enum Values

To access an enum value, use the enum name followed by a dot and the name of the value.

C# Example 
enum Level
{
    Low,
    Medium,
    High
}

Level level = Level.Medium;

Console.WriteLine(level);

Output

The output will be:

Medium

The variable level stores the enum value Medium.

Values

Enum Numeric Values

By default, enum members are assigned integer values starting from 0.

C# Example 
enum Level
{
    Low,
    Medium,
    High
}

Console.WriteLine((int)Level.Low);
Console.WriteLine((int)Level.Medium);
Console.WriteLine((int)Level.High);

Output

0
1
2

You can convert an enum member to an integer by using explicit casting.

Custom Values

Assign Custom Values

You can also assign your own numeric values to enum members.

C# Example 
enum Level
{
    Low = 1,
    Medium = 5,
    High = 10
}
  • Low has the value 1.
  • Medium has the value 5.
  • High has the value 10.
Benefits

Why Use Enums?

  • Enums make code more readable.
  • They represent a fixed set of related values.
  • They make code easier to understand and maintain.
  • They can replace unclear numeric values with meaningful names.
Example: Instead of writing 1 to represent a status, you can write Status.Active, which makes the code much clearer.
