Switch

C# Switch

Practice using the switch statement in C# to select and execute a block of code based on the value of an expression.

Example 01

Match a Day of the Week

Create a variable containing a day number and use a switch statement to display the corresponding day name. 

int day = 3;

// Use switch to display the day name
Answer 
int day = 3;

switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;

    case 2:
        Console.WriteLine("Tuesday");
        break;

    case 3:
        Console.WriteLine("Wednesday");
        break;

    default:
        Console.WriteLine("Invalid day");
        break;
}
Example 02

Simple Calculator with Switch

Create a simple calculator that uses a switch statement to perform an operation based on the selected operator. 

double x = 10;
double y = 5;
char operation = '+';

// Use switch to perform the operation
Answer 
double x = 10;
double y = 5;
char operation = '+';

switch (operation)
{
    case '+':
        Console.WriteLine(x + y);
        break;

    case '-':
        Console.WriteLine(x - y);
        break;

    case '*':
        Console.WriteLine(x * y);
        break;

    case '/':
        Console.WriteLine(x / y);
        break;

    default:
        Console.WriteLine("Invalid operation");
        break;
}

C# Exceptions (Try...Catch)

Practice handling errors in C# using try, catch, and finally blocks to prevent your program from stopping unexpectedly.

Example 01

Handle a Division by Zero Exception

Use try and catch to handle an error that occurs when dividing a number by zero. 

int number = 10;
int divisor = 0;

// Handle the division error
Answer 
int number = 10;
int divisor = 0;

try
{
    int result = number / divisor;

    Console.WriteLine(result);
}
catch (DivideByZeroException)
{
    Console.WriteLine("Cannot divide by zero.");
}
Example 02

Try...Catch...Finally

Use try, catch, and finally to handle an invalid number conversion. 

string input = "Hello";

// Try to convert the text into an integer
Answer 
string input = "Hello";

try
{
    int number = Convert.ToInt32(input);

    Console.WriteLine(number);
}
catch (FormatException)
{
    Console.WriteLine("Invalid number format.");
}
finally
{
    Console.WriteLine("Finished.");
}
