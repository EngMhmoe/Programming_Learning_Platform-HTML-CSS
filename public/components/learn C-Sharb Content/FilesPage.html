C# Files

Learn how to create, write, read, and manage files in C# using the System.IO namespace.

Previous Next
Files

What Are Files?

Files are used to store data permanently on a computer. C# provides several classes for working with files and folders.

Most file operations in C# are available through the System.IO namespace.

Common file operations: You can create, write, read, copy, move, and delete files using C#.
System.IO

The System.IO Namespace

The System.IO namespace contains classes that allow you to work with files, directories, streams, and other input/output operations.

C# Example 
using System.IO;

Why Use System.IO?

Without importing the namespace, you may need to use the complete class names such as System.IO.File.

Using the namespace makes file-related code shorter and easier to read.

Create

Create a File

You can use File.Create() to create a new file.

C# Example 
using System.IO;

File.Create("example.txt");

How It Works

The File.Create() method creates a file named example.txt.

If the file already exists, it is overwritten.

Write

Write to a File

The File.WriteAllText() method creates a file and writes text into it.

C# Example 
using System.IO;

File.WriteAllText(
    "example.txt",
    "Hello from C#!"
);

What Happens?

The method creates example.txt if it does not exist.

It then writes the specified text into the file. If the file already contains text, the existing content is replaced.

Read

Read a File

You can use File.ReadAllText() to read all text from a file.

C# Example 
string content =
    File.ReadAllText("example.txt");

Console.WriteLine(content);

How It Works

The ReadAllText() method reads all the text stored inside the file.

The returned text is stored in the content variable.

Check

Check If a File Exists

Before reading or deleting a file, you can check whether the file exists by using File.Exists().

C# Example 
if (File.Exists("example.txt"))
{
    Console.WriteLine("File exists.");
}
Important: Checking whether a file exists can help prevent errors when working with files that may not be available.
Delete

Delete a File

The File.Delete() method removes a file from the computer.

C# Example 
File.Delete("example.txt");

Safe Deletion

It is often useful to check whether the file exists before trying to delete it.
