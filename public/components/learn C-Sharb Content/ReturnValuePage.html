Return Values

Return Values

Methods can return a value instead of simply performing an action.

In the previous page , we used the void keyword in all examples. This means that the method does not return a value.

If you want a method to return a value, you can use a data type such as int or double instead of void . Then, use the return keyword inside the method.

Example

Returning a Value

The following method returns an integer value after adding 5 to the parameter.

C# Example 
static int MyMethod(int x)
{
    return 5 + x;
}

static void Main(string[] args)
{
    Console.WriteLine(MyMethod(3));
}

// Outputs 8 (5 + 3)

The method is declared with int, so it must return an integer value.

The return keyword sends the calculated value back to the place where the method was called.

In this example, MyMethod(3) returns 8.

Example

Returning the Sum of Two Parameters

A method can also return the result of working with multiple parameters.

C# Example 
static int MyMethod(int x, int y)
{
    return x + y;
}

static void Main(string[] args)
{
    Console.WriteLine(MyMethod(5, 3));
}

// Outputs 8 (5 + 3)

The method receives two parameters: x and y.

It returns their sum using the return keyword.

Example

Store the Return Value in a Variable

You can store the returned value in a variable, which can make the code easier to read and maintain.

C# Example 
static int MyMethod(int x, int y)
{
    return x + y;
}

static void Main(string[] args)
{
    int z = MyMethod(5, 3);

    Console.WriteLine(z);
}

// Outputs 8 (5 + 3)

The returned value from MyMethod(5, 3) is stored in the variable z.

The value of z is then printed using Console.WriteLine().

Tip: Storing a returned value in a variable can make your code easier to read and maintain.
