Conditions

C# Conditions and If Statements

Conditions allow your program to make decisions based on whether an expression is true or false.

C# supports common comparison conditions that can be used to compare values.

  • Less than: a < b
  • Less than or equal to: a <= b
  • Greater than: a > b
  • Greater than or equal to: a >= b
  • Equal to: a == b
  • Not equal to: a != b
Note: These comparison operators produce a Boolean result: either true or false.
Conditional Statements

Conditional Statements in C#

C# provides several statements for controlling which blocks of code should be executed.

  • Use if to execute a block of code when a condition is true.
  • Use else to execute a block of code when the condition is false.
  • Use else if to test another condition when the previous condition is false.
  • Use switch when you need to choose between multiple alternative cases.
Important: This page focuses on the if statement. The else, else if, and switch statements are covered in their own lessons.
If Statement

The if Statement

Use the if statement to specify a block of C# code that should be executed when a condition is true.

Syntax 
if (condition)
{
    // block of code to be executed if the condition is true
}
Note: The if keyword must be written in lowercase. C# is case-sensitive, so If or IF will cause an error.
Example

Checking a Condition

In the example below, we check whether 20 is greater than 18. If the condition is true, a message is printed to the console.

Example 
if (20 > 18)
{
    Console.WriteLine("20 is greater than 18");
}
Variables

Using Variables in an if Statement

You can also compare variables inside an if statement.

Example 
int x = 20;
int y = 18;

if (x > y)
{
    Console.WriteLine("x is greater than y");
}

Example Explained

In the example above, we create two variables, x and y. We then use the > operator to check whether x is greater than y. Since x is 20 and y is 18, the condition is true and the message is displayed.
