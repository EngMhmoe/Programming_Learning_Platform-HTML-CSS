C# Else If Statement

Learn how to use the else if statement in C# to check another condition when the previous condition is false.

Previous Next
Else If Statement

The else if Statement

Use the else if statement to specify a new condition when the previous if condition is false.

Syntax 
if (condition1)
{
    // block of code to be executed if condition1 is true
}
else if (condition2)
{
    // block of code to be executed if condition1 is false and condition2 is true
}
else
{
    // block of code to be executed if condition1 and condition2 are false
}
Note: You can use multiple else if statements when you need to check several different conditions.
Example

Using if...else if...else

This example checks the value of time using multiple conditions.

Example 
int time = 22;

if (time < 10)
{
    Console.WriteLine("Good morning.");
}
else if (time < 20)
{
    Console.WriteLine("Good day.");
}
else
{
    Console.WriteLine("Good evening.");
}

// Outputs "Good evening."
Explanation

Example Explained

The variable time has the value 22. First, the program checks whether time < 10 . Since 22 is not less than 10, the first condition is false. The program then checks the else if condition time < 20 . This condition is also false because 22 is not less than 20. Therefore, the else block runs and prints "Good evening." .

Remember: If the value of time were 14, the first condition would be false, but time < 20 would be true. The else if block would then execute and print "Good day." .
