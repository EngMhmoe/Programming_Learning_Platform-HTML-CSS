Comparison

Comparison Operators

Comparison operators are used to compare two values or variables.

Comparison operators are used to compare two values or variables. This is important in programming because it helps us find answers and make decisions.

The result of a comparison is always either True or False . These are Boolean values.

For example, the expression x > y checks whether the value of x is greater than the value of y.

Example 
int x = 5;
int y = 3;

Console.WriteLine(x > y);

The expression x > y returns True because 5 is greater than 3.

Operators

List of Comparison Operators

C# provides several comparison operators for comparing values.

Operator Name Example
== Equal to x == y
!= Not equal x != y
> Greater than x > y
< Less than x < y
>= Greater than or equal to x >= y
<= Less than or equal to x <= y
Boolean Result

Comparison Results

Comparison expressions always produce a Boolean result.

Example 
int x = 10;
int y = 10;

Console.WriteLine(x == y);

Because x and y both contain 10, the comparison returns True .

Remember:

Comparison operators do not change the values of the variables. They only compare their values and return a Boolean result.
