Identifiers

What Are Identifiers?

All C# variables must be identified with unique names. These unique names are called identifiers.

Identifiers can be short names, such as x and y, or more descriptive names, such as age, sum, and totalVolume.

Note: It is recommended to use descriptive names in order to create understandable and maintainable code.
Example

Use Descriptive Names

Descriptive variable names make your code easier to understand and maintain.

C# Example 
// Good
int minutesPerHour = 80;

// OK, but not so easy to understand what m actually is
int m = 80;
Naming Rules

Rules For Naming Variables

C# identifiers must follow specific naming rules.

  • Names can contain letters, digits, and the underscore character _.
  • Names must begin with a letter or an underscore.
  • Names should start with a lowercase letter and cannot contain whitespace.
  • Names are case-sensitive. myVar and myvar are different variables.
  • Reserved words, such as C# keywords like int or double, cannot be used as variable names.
