Polymorphism

Polymorphism and Overriding Methods

Polymorphism means "many forms", and it occurs when we have many classes that are related to each other by inheritance.

Like we specified in the previous chapter, inheritance lets us inherit fields and methods from another class. Polymorphism uses those methods to perform different tasks. This allows us to perform a single action in different ways.

For example, think of a base class called Animal that has a method called animalSound(). Derived classes of Animal could be Pigs, Cats, Dogs, and Birds, and they can provide their own implementation of an animal sound.

Example 
class Vehicle
{
    public string brand = "Ford";

    public void Honk()
    {
        Console.WriteLine("Tuut, tuut!");
    }
}

class Car : Vehicle
{
    public string modelName = "Mustang";
}

class Program
{
    static void Main(string[] args)
    {
        // Create a myCar object
        Car myCar = new Car();

        // Call the Honk() method from the Vehicle class
        myCar.Honk();

        // Display values inherited from Vehicle and defined in Car
        Console.WriteLine(
            myCar.brand + " " + myCar.modelName
        );
    }
}

// Outputs:
// Tuut, tuut!
// Ford Mustang

Why and When to Use Inheritance?

Inheritance is useful for code reusability: reuse fields and methods of an existing class when you create a new class.

Tip: Also take a look at the next chapter, Polymorphism, which uses inherited methods to perform different tasks.
Keyword

The sealed Keyword

If you don't want other classes to inherit from a class, use the sealed keyword.

If you try to inherit from a sealed class, C# will generate a compiler error.

Example 
sealed class Vehicle
{
    // class members
}

class Car : Vehicle
{
    // Error: cannot inherit from a sealed class
}
Compiler Error 'Car': cannot derive from sealed type 'Vehicle'
