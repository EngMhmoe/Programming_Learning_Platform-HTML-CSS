Display Variables

C# Display Variables

The WriteLine() method is often used to display variable values in the console window.

You can display a variable by passing its name to WriteLine() . This allows your program to show the value stored inside the variable.

Example 
string name = "John";
Console.WriteLine(name);
Combining Values

Combine Text and Variables

To combine text and a variable, use the + character.

Example 
string name = "John";
Console.WriteLine("Hello " + name);
Note: The + operator joins the text with the value stored in the variable.
Multiple Variables

Combine Variables

You can also use the + character to add one variable to another variable.

Example 
string firstName = "John";
string lastName = "mohamed";
string fullName = firstName + lastName;
Console.WriteLine(fullName);

In this example, the values of firstName and lastName are combined and stored inside fullName .

Numeric Values

Display Numeric Values

For numeric values, the + character works as a mathematical operator.

Example 
int x = 10;
int y = 20;

Console.WriteLine(x + y); // Print the value of x + y

What Happens Here?

  • x stores the value 10 .
  • y stores the value 20 .
  • The expression x + y calculates 30 .
  • The WriteLine() method displays 30 in the console.
Important: When working with numeric variables, the + operator performs mathematical addition.
