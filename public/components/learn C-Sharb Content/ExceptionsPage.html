Exceptions

What Are Exceptions?

An exception is an error that occurs while a C# program is running. Exceptions can interrupt the normal flow of the program if they are not handled properly.

C# provides several keywords for handling exceptions, including try, catch, finally, and throw.

  • try: Contains code that may cause an exception.
  • catch: Handles the exception when one occurs.
  • finally: Contains code that runs whether an exception occurs or not.
  • throw: Allows you to create and throw an exception manually.
Try & Catch

Try and Catch

The try block contains code that may cause an exception. The catch block runs when an exception occurs.

C# Example 
try
{
    int number = int.Parse("Hello");
}
catch
{
    Console.WriteLine("Invalid number.");
}

How It Works

The code inside the try block attempts to convert the text "Hello" into an integer.

Because the text is not a valid integer, C# throws an exception and the catch block handles it.

Finally

Finally

The finally block contains code that should run whether an exception occurs or not.

C# Example 
try
{
    Console.WriteLine("Trying...");
}
catch
{
    Console.WriteLine("Something went wrong.");
}
finally
{
    Console.WriteLine("Finished.");
}
Note: The finally block is useful when you need to perform cleanup operations after the code finishes.
Throw

Throw an Exception

The throw keyword allows you to create and throw an exception manually when a specific condition is not valid.

C# Example 
int age = 15;

if (age < 18)
{
    throw new Exception(
        "You must be 18 or older."
    );
}

Why Use Throw?

You can use throw when your program needs to report a specific invalid condition.

Complete Example

Complete Exceptions Example

Here is a complete example that uses try, catch, and finally together.

C# Example 
try
{
    int number = int.Parse("25");

    Console.WriteLine(number);
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
finally
{
    Console.WriteLine("Program finished.");
}
