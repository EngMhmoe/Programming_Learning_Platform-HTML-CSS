C# Programming

C# Sort Arrays

Learn how to sort arrays in C# using the Sort method and other useful methods from the System.Linq namespace.

Previous Next
Arrays

Sort an Array

There are many array methods available. For example, Sort() sorts an array alphabetically or in ascending order.

Example 
// Sort a string
string[] cars = { "Volvo", "BMW", "Ford", "Mazda" };

Array.Sort(cars);

foreach (string car in cars)
{
    Console.WriteLine(car);
}
Example

Sort Numbers

The Sort() method can also be used with numeric arrays to arrange their values in ascending order.

Example 
// Sort integers
int[] myNumbers = {10, 20, 30, 40};

Array.Sort(myNumbers);

foreach (int number in myNumbers)
{
    Console.WriteLine(number);
}
System.Linq

System.Linq Namespace

Other useful array methods, such as Min(), Max(), and Sum(), can be found in the System.Linq namespace.

Example 
using System;
using System.Linq;

int[] myNumbers = {10, 20, 30, 40};

Console.WriteLine(myNumbers.Max());
// Returns the largest value

Console.WriteLine(myNumbers.Min());
// Returns the smallest value

Console.WriteLine(myNumbers.Sum());
// Returns the sum of elements

Max() returns the largest value in the array.

Min() returns the smallest value in the array.

Sum() returns the total of all values in the array.

Note: You will learn more about other namespaces and LINQ features in later C# topics.
