Algorithm Characteristics

Learn the essential properties of a well-defined algorithm, from clear instructions and valid inputs to correct results and a finite number of steps.

Previous Next
Lesson Overview

What Makes an Algorithm Good?

An algorithm is more than a sequence of instructions. Its steps should be understandable, its result should solve the intended problem, and its execution should follow a clear and limited process.

Clear, Correct, and Complete

A well-designed algorithm defines what information it receives, what result it produces, and how it reaches that result through precise steps.

Different textbooks may group or name algorithm characteristics differently. In this lesson, we will focus on the commonly taught properties and the practical meaning of each one.

Input & Output

1. Input and Output

An algorithm receives the information it needs and produces a result. Some algorithms require multiple inputs, while others can work without any input.

Input

What Goes In?

The values or information provided to the algorithm before or during its execution.

Example numberA = 5 numberB = 3
Output

What Comes Out?

The result produced after the algorithm processes its inputs according to its instructions.

Example result = 8

For an algorithm that adds two numbers, the inputs are the two numbers and the output is their sum. An algorithm that displays a fixed message may not need an input.

Definiteness

2. Clear and Unambiguous Steps

Every instruction should have a precise meaning. The person or computer following the algorithm should not have to guess what a step means.

Unclear Instruction

Make the number better.

What does "better" mean?

Clear Instruction

Add 1 to the number.

The operation is specific.

Why Does Clarity Matter?

Precise instructions make an algorithm easier to implement, test, understand, and maintain. They also reduce the chance of different interpretations.

Finiteness

3. Finish After a Finite Number of Steps

An algorithm should eventually stop after completing its task. It must not continue executing forever when it is expected to produce a final result.

01

Start

Receive the required input.

02

Process

Perform the required operations.

03

Stop

Return or display the result.

A loop can be part of a valid algorithm as long as its execution is properly controlled for the intended input. An infinite loop that never completes the required task violates the finiteness requirement.

Effectiveness

4. Perform Practical Operations

Each step should be simple enough to be carried out using the available operations and resources. The instructions must be executable, not just theoretical.

Performable Operations

Operations such as adding numbers, comparing values, assigning variables, and reading data can be carried out through defined instructions.

Feasible Steps

Each step should be possible to execute in practice using the computational model and resources available.

Effectiveness does not mean that an algorithm must be the fastest possible solution. It means its individual operations are sufficiently basic and executable.

Correctness & Generality

5. Produce Correct Results

A useful algorithm must solve the intended problem correctly for every valid input within its defined requirements.

Correctness

The algorithm produces the expected output when given valid input.

5 + 3 = 8

Generality

The algorithm can handle the range of inputs and cases defined by the problem, not just one example.

2 + 4 = 6 10 + 7 = 17

An addition algorithm should not work only for 5 and 3. It should correctly add other valid pairs of numbers within its specified input range.

Practical Example

Put the Characteristics Together

Consider an algorithm that reads two numbers, calculates their sum, and displays the result.

AddTwoNumbers.pseudo 
START

INPUT numberA
INPUT numberB

result = numberA + numberB

OUTPUT result

END
Input

Receives numberA and numberB.

Output

Displays the calculated result.

Definiteness

Each instruction has a clear meaning.

Finiteness

The sequence reaches END after a limited number of steps.

Effectiveness

Reading, adding, and displaying are executable operations.

Correctness

The result is the sum of the two valid input numbers.

Key Takeaways

What Should You Remember?

These characteristics help us understand whether an algorithm is clearly defined and suitable for solving a problem.

  • Input and Output: Define the information received and the result produced.
  • Definiteness: Every step must be clear and unambiguous.
  • Finiteness: The algorithm should finish after a finite number of steps.
  • Effectiveness: Every operation must be executable in practice.
  • Correctness and Generality: The algorithm should solve the problem correctly for its intended range of valid inputs.
