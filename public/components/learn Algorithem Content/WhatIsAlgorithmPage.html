What Is an Algorithm?

Understand what an algorithm really is, explore its basic structure, and learn how a clear sequence of instructions can solve a problem.

Previous Next
Definition

What Exactly Is an Algorithm?

An algorithm is a finite sequence of clear, ordered instructions designed to solve a problem or complete a specific task.

In Simple Words

A step-by-step plan for solving a problem.

It describes what needs to happen and in what order, without requiring a specific programming language.

Ordered Instructions

Steps follow a logical sequence so the solution can be carried out correctly.

A Clear Goal

The instructions are designed to solve a defined problem or produce a result.

A Finite Process

A valid algorithm for a task should eventually finish rather than continue indefinitely.

Basic Structure

Input, Process, and Output

A useful way to understand many algorithms is to look at three basic parts: the information they receive, the operations they perform, and the result they produce.

Not every algorithm must receive input or produce a visible output in exactly the same way. These three parts are a helpful general model for many problem-solving tasks.
Practical Example

Find the Larger of Two Numbers

Suppose you have two numbers and want to determine which one is larger. An algorithm can describe exactly how to make that decision.

First Number 14
Second Number 9
01

Read the Two Numbers

Store the first number as a = 14 and the second as b = 9.

02

Compare the Values

Check whether a is greater than b.

03

Choose the Result

Since 14 is greater than 9, the first number is larger.

Expected Result 14 is the larger number.
Representing an Algorithm

How Can We Write an Algorithm?

Before writing actual code, we can express the solution in plain language or pseudocode. Pseudocode describes the logic in a structured, code-like form without following the exact syntax of a specific programming language.

Plain Language

  1. Start.
  2. Read two numbers.
  3. Compare the numbers.
  4. Display the larger number.
  5. Finish.

Pseudocode

Pseudocode 
START

INPUT a, b

IF a > b THEN
    OUTPUT a
ELSE IF b > a THEN
    OUTPUT b
ELSE
    OUTPUT "Both numbers are equal"
END IF

END
Pseudocode is a planning tool, not a programming language that must follow one universal syntax. Its purpose is to make the solution logic easier to understand before implementation.
From Logic to Code

Implementing the Same Algorithm

Once the steps are clear, we can implement them in a programming language. The code below follows the same comparison logic.

JavaScript 
const a = 14;
const b = 9;

if (a > b) {
    console.log(a);
} else if (b > a) {
    console.log(b);
} else {
    console.log("Both numbers are equal");
}

// Output: 14

The algorithm describes the comparison and the possible outcomes.

The JavaScript code uses the language's syntax to carry out those steps.

The output for the example inputs is 14.

A Good Algorithm

What Makes an Algorithm Useful?

An algorithm should do more than list instructions. Its steps need to be understandable and appropriate for the problem being solved.

Clear Steps

Each instruction should be understandable and leave little room for ambiguity.

Correct Results

The steps should produce the expected result for valid inputs covered by the problem.

Termination

The algorithm should reach an ending point after a finite number of steps.

Testable Logic

You should be able to trace the steps with sample inputs and check the results.

Algorithm characteristics will be explored in greater detail in the upcoming Algorithm Characteristics lesson.
Common Misconceptions

What an Algorithm Is Not

Understanding what an algorithm is also means avoiding a few common misunderstandings.

An Algorithm Is Not a Programming Language

An algorithm describes the solution logic. A programming language provides the syntax used to implement that logic.

An Algorithm Is Not Just Any List of Steps

The steps must be relevant to the problem, arranged logically, and capable of leading to the intended result.

There Is Not Always Only One Solution

Different algorithms can solve the same problem. They may differ in clarity, performance, or resource usage.

Key Takeaways

What Should You Remember?

  • An algorithm is a finite sequence of instructions designed to solve a problem or complete a task.
  • Input, process, and output are useful concepts for understanding how many algorithms work.
  • You can describe an algorithm using plain language or pseudocode before writing program code.
  • The same algorithmic logic can be implemented in different programming languages.
  • Clear steps and testing help you check whether an algorithm solves the intended problem.
