Introduction to Algorithms

Discover how algorithms turn problems into clear, step-by-step solutions, and learn how to describe a solution before writing the code.

Previous Next
Lesson Overview

What Is This Lesson About?

Before studying individual algorithms, it helps to understand the general idea behind them. An algorithm gives us an organized way to move from a problem to a solution through a sequence of understandable steps.

Start With a Problem

Identify what you need to solve and what information is available.

Plan the Steps

Arrange clear instructions that lead from the input to the desired result.

Implement the Solution

Translate the planned steps into a programming language when you are ready to code.

The Basic Idea

From a Problem to a Solution

Imagine you need to calculate the total price of two products. Before choosing a programming language, you can describe the solution in simple steps.

01

Understand the Input

Get the price of the first product and the price of the second product.

02

Process the Information

Add the two prices together to calculate the total.

03

Produce the Output

Display the calculated total to the user.

An algorithm describes the steps used to solve a problem. The code is the implementation of those steps in a programming language.
Everyday Example

An Algorithm Outside Programming

Algorithms are not limited to computers. Everyday tasks can also be described as ordered steps. Consider making a cup of tea.

Making a Cup of Tea

A simple sequence of instructions

  1. 1

    Fill a kettle with water.

  2. 2

    Heat the water until it boils.

  3. 3

    Place a tea bag in a cup.

  4. 4

    Pour the hot water into the cup.

  5. 5

    Wait for the tea to brew, then serve it.

The instructions have an order, and each step contributes to the final result. Programming algorithms follow the same general idea, although their steps must be precise enough to process data and handle the problem correctly.

Important Difference

Algorithm vs. Program Code

An algorithm explains the logic of a solution. Program code expresses that logic using the syntax and rules of a specific programming language.

Algorithm

  • Describes the solution steps.
  • Focuses on the problem-solving logic.
  • Can be written in plain language or pseudocode.
Example

Read two numbers

Add the numbers

Display the result

Program Code

  • Uses a programming language.
  • Follows specific syntax rules.
  • Can be executed by a suitable runtime or compiler.
JavaScript 
const firstNumber = 10;
const secondNumber = 5;

const total =
    firstNumber + secondNumber;

console.log(total);

// Output: 15
The same algorithmic idea can often be implemented in different programming languages. The syntax may change, but the underlying logic can remain the same.
Problem-Solving Approach

How Should You Approach a Problem?

When you face a programming problem, avoid jumping directly into writing code. First, understand the requirements and plan a solution.

1. Understand the Problem

Identify exactly what the problem asks you to find, calculate, or produce.

2. Identify Inputs and Outputs

Determine what information the solution receives and what result it should return.

3. Break It Into Steps

Divide the solution into small, logical instructions that can be followed in order.

4. Test the Logic

Walk through the steps using sample values and check whether the result is correct.

5. Implement and Improve

Write the code, test different cases, and consider whether the solution can be improved.

Key Takeaways

What Should You Remember?

  • An algorithm is a sequence of steps designed to solve a problem or complete a task.
  • A clear algorithm starts with a well-understood problem and produces the expected result.
  • Planning the solution before coding makes the logic easier to understand and test.
  • An algorithm and its implementation are related, but they are not the same thing.
  • Testing with different inputs helps reveal mistakes in the planned steps or their implementation.
