Description

Learn Strapi Back-End

Strapi is an open-source headless CMS that provides developers with a flexible back-end for creating and managing content through APIs. It separates the content management system from the front-end application.

In this course, you will learn how to create Strapi projects, define content types, manage data, work with APIs, configure permissions, and connect Strapi with front-end applications.

What Will You Learn?

Introduction to Strapi

Understand what Strapi is and why developers use it as a headless CMS.

Headless CMS

Strapi Admin Panel
