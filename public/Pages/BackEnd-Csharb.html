Understand the Basics of C# Back-End

Learn how C# is used for back-end development and how .NET, ASP.NET Core, APIs, databases, and server-side applications work together.

Description

Learn C# Back-End

C# is a modern programming language developed by Microsoft and widely used to build reliable and scalable applications. In back-end development, C# is commonly used with .NET and ASP.NET Core to create server-side applications and Web APIs.

In this course, you will learn the fundamentals of C# back-end development, including routing, controllers, models, dependency injection, databases, CRUD operations, authentication, RESTful APIs, and connecting front-end applications with a C# back-end.

Course Content

What Will You Learn?

Introduction to C# Back-End

Understand how C# is used to build server-side applications.

.NET and ASP.NET Core

Learn the role of .NET and ASP.NET Core in back-end development.

Creating a Web API

Learn how to create a basic ASP.NET Core Web API using C#.

Routing

Understand how routes connect URLs to back-end endpoints.

HTTP Methods

Learn GET, POST, PUT, PATCH, and DELETE and when to use each method.

Controllers

Learn how controllers organize API endpoints and application logic.

Models

Understand how models represent application data.

Dependency Injection

Learn how ASP.NET Core manages and injects application services.

Entity Framework Core

Learn how to work with databases using Entity Framework Core.

CRUD Operations

Build Create, Read, Update, and Delete operations for back-end applications.

Authentication

Understand how to protect back-end resources and user accounts.

RESTful APIs

Learn the main principles for designing clean and scalable RESTful APIs.

Connecting Front-End Applications

Connect React and JavaScript front-end applications with C# back-end APIs.
