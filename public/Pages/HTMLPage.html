Description

Learn HTML5

HTML5 is the standard markup language used to structure content on the web. In this course, you will learn how HTML works and how to use HTML elements to organize text, links, images, lists, tables, forms and other content inside web pages.

Course Content

What Will You Learn?

Introduction to HTML5

Understand what HTML5 is and its role in building web pages.

HTML Document Structure

Learn the basic structure of a complete HTML document.

HTML Elements and Tags

Understand elements, tags, and how they organize webpage content.

Headings and Text Formatting

Learn how to create headings, paragraphs, and formatted text.

Links and Navigation

Create links and connect different pages together.

Images and Multimedia

Learn how to add images and multimedia content to web pages.

Lists

Work with ordered and unordered lists to organize information.

Tables

Learn how to organize structured data using HTML tables.

Forms and Inputs

Create forms and collect information using different input elements.

Semantic HTML

Understand semantic elements and how they improve webpage structure.

HTML Attributes

Learn how attributes provide additional information to HTML elements.

Meta Tags

Understand important metadata used by browsers and search engines.

Building a Complete HTML Page

Combine the fundamentals to build a complete structured HTML page.
