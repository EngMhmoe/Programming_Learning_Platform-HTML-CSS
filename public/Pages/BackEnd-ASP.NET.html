Course Overview

Understand the Basics of ASP.NET

Learn how ASP.NET Core works and how it is used with C# to build Web APIs, handle HTTP requests, organize application logic, and create modern back-end applications.

Description

Learn ASP.NET

ASP.NET Core is a cross-platform framework developed by Microsoft for building modern web applications and back-end services. It works with C# and .NET to provide a powerful environment for developing Web APIs and server-side applications.

In this course, you will learn the fundamentals of ASP.NET Core, including project structure, routing, HTTP methods, controllers, models, dependency injection, middleware, Web APIs, authentication, and how to connect your back-end with databases and front-end applications.

Course Content

What Will You Learn?

Introduction to ASP.NET Core

Understand what ASP.NET Core is and why it is used for modern back-end development.

.NET and ASP.NET Core

Learn the relationship between .NET, ASP.NET Core, and C#.

Creating an ASP.NET Project

Project Structure

Understand the main files and folders inside an ASP.NET Core project.

Routing

Learn how URLs are mapped to endpoints and application actions.

HTTP Methods

Controllers

Models

Understand how models represent and transfer application data.

Dependency Injection

Middleware

Web APIs

Authentication
