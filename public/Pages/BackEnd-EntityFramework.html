Course Overview

Understand the Basics of Entity Framework

Learn how Entity Framework Core connects C# applications with relational databases and makes database operations easier through models, LINQ, migrations, and DbContext.

Description

Learn Entity Framework

Entity Framework Core is an Object-Relational Mapper (ORM) for .NET. It allows developers to work with relational databases through C# classes and objects instead of writing SQL queries for every database operation.

In this course, you will learn the fundamentals of Entity Framework Core, including DbContext, entities, database providers, relationships, migrations, LINQ queries, CRUD operations, change tracking, asynchronous database operations, and connecting EF Core with ASP.NET Core applications.

Course Content

What Will You Learn?

Introduction to Entity Framework

Understand what Entity Framework Core is and why it is used in back-end development.

ORM and EF Core

Learn how Object-Relational Mapping connects C# objects with database tables.

Installing Entity Framework Core

Learn how to install EF Core packages and prepare a project for database work.

DbContext

Understand DbContext and how it manages communication with the database.

Entities and Models

Learn how C# classes are mapped to database tables and records.

Database Providers

Learn how EF Core works with different relational database providers.

Relationships

Understand one-to-one, one-to-many, and many-to-many relationships.

Migrations

Learn how to create and update database structures using EF Core migrations.

LINQ Queries

Learn how to query database data using LINQ and C# expressions.

CRUD Operations

Build Create, Read, Update, and Delete operations using Entity Framework Core.

Change Tracking

Understand how EF Core tracks changes to entities before saving them.

Async Database Operations

Learn how to perform database operations asynchronously with EF Core.

Using EF Core with ASP.NET Core APIs

Connect Entity Framework Core with ASP.NET Core Web APIs and build data-driven applications.
